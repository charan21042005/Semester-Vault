## 1. Why Python for MongoDB?

| Reason | Meaning |
|-----------|------------|
| Simple syntax | fast to learn and write |
| Data libraries | pandas, NumPy, scikit-learn |
| AI/ML ecosystem | TensorFlow, PyTorch, scikit-learn |

## 2. What is PyMongo?

> PyMongo is the official MongoDB driver for Python.

Same role as the `mongodb` package in Node:

```
Python code  →  PyMongo (driver)  →  MongoDB
```

Remember the Part 1 picture:

```
Application → Driver → Database
   Python      PyMongo   MongoDB
```

There are also async Python drivers for async frameworks, but the standard synchronous PyMongo is what your syllabus names, so that's our focus.

|-----------|----------------|-----------|

## 7. `MongoClient` — the connection object

```python
from pymongo import MongoClient

client = MongoClient("mongodb://localhost:27017")
```

Key facts:

```
MongoClient(...) is created lazily:
  it starts background connection logic but does not raise an error immediately
  if the server is unreachable. The error appears when you run an operation.
```

So to **test** the connection, do a real command:

```python
client.admin.command("ping")
```

## 8. First program — connect and ping

`app.py`:

```python
import os
from dotenv import load_dotenv
from pymongo import MongoClient
from pymongo.errors import PyMongoError

load_dotenv()
uri = os.getenv("MONGODB_URI")

client = MongoClient(uri, serverSelectionTimeoutMS=5000)

try:
    client.admin.command("ping")
    print("✅ Connected to MongoDB")
except PyMongoError as e:
    print("❌ Connection failed:", e)
finally:
    client.close()
```

Run:

```
python app.py
```

Read it:

```
load_dotenv()                    → read .env into environment
os.getenv("MONGODB_URI")         → get the URI
MongoClient(uri, timeout)        → create client (fail fast in 5 seconds if unreachable)
client.admin.command("ping")     → real server round trip
except PyMongoError              → base class of PyMongo exceptions
client.close()                   → release connections
```

`serverSelectionTimeoutMS=5000` shortens the default wait (30 seconds) so errors show quickly while learning.

## 9. Database and collection access

The chain, again:

```
MongoClient  →  Database  →  Collection  →  Documents
```

Two equivalent syntaxes:

### Attribute style

```python
db = client.collegeDB
students = db.students
```

### Dictionary (bracket) style ⭐ recommended

```python
db = client["collegeDB"]
students = db["students"]
```

Why bracket style is recommended:

```
Names with hyphens or spaces (e.g. "my-db") don't work as attributes.
Names stored in variables only work with brackets.
It avoids confusion with real attributes/methods.
```

Shell → Python:

| Shell | PyMongo |
|----------|------------|
| `use collegeDB` | `db = client["collegeDB"]` |
| `db.students` | `students = db["students"]` |

As always, databases and collections are created lazily on first write.

## 11. BSON ↔ Python type mapping

You learned BSON types in Unit II. Here's how they appear in Python.

| BSON type | Python type |
|--------------|------------------|
| String | `str` |
| Int32 / Int64 | `int` |
| Double | `float` |
| Boolean | `bool` |
| Null | `None` |
| Array | `list` |
| Embedded document | `dict` |
| Date | `datetime.datetime` |
| ObjectId | `bson.objectid.ObjectId` |
| Decimal128 | `bson.decimal128.Decimal128` |
| Binary | `bytes` / `bson.binary.Binary` |

### ObjectId

```python
from bson.objectid import ObjectId

oid = ObjectId("6650a1b2c3d4e5f607182930")
students.find_one({"_id": oid})
```

Trap 🚨: searching with a plain string for `_id` finds nothing, same as in Node.

### Dates

```python
from datetime import datetime, timezone

doc = {"name": "Rahul", "joined": datetime.now(timezone.utc)}
```

PyMongo stores `datetime` as BSON Date (in UTC).

Timezone note:

```
MongoDB stores dates in UTC.
By default PyMongo returns naive datetimes (no tzinfo).
Use tz_aware=True in MongoClient if you want timezone-aware values.
```

### Money-like precision

Floats can be imprecise. For exact decimals:

```python
from bson.decimal128 import Decimal128
from decimal import Decimal

price = Decimal128(Decimal("499.99"))
```

## 12. First insert and read

```python
import os
from dotenv import load_dotenv
from pymongo import MongoClient

load_dotenv()
client = MongoClient(os.getenv("MONGODB_URI"))
students = client["collegeDB"]["students"]

# INSERT
result = students.insert_one({"name": "Rahul", "branch": "CSE", "cgpa": 8.7})
print("Inserted id:", result.inserted_id)

# READ
doc = students.find_one({"name": "Rahul"})
print(doc)

client.close()
```

Output (roughly):

```
Inserted id: 6650a1b2c3d4e5f607182930
{'_id': ObjectId('6650a1b2c3d4e5f607182930'), 'name': 'Rahul', 'branch': 'CSE', 'cgpa': 8.7}
```

Look at what happened:

```
dict → BSON → MongoDB → BSON → dict
```

And notice the naming style:

| Node.js (camelCase) | PyMongo (snake_case) |
|--------------------------|--------------------------|
| `insertOne` | `insert_one` |
| `findOne` | `find_one` |
| `updateMany` | `update_many` |
| `deleteOne` | `delete_one` |
| `countDocuments` | `count_documents` |

Same operations, Pythonic names.

## 13. Python-specific filter reminders

```python
students.find({"cgpa": {"$gte": 8}})          # operators are still strings with $
students.find({"branch": "CSE", "year": 4})    # implicit AND
students.find({"isActive": True})              # True, not true
students.find({"mentor": None})                # matches null/missing
```

Operators are quoted strings (`"$gte"`) because Python dictionary keys must be strings (JavaScript also allows unquoted keys, Python does not).

## 14. Connection pooling and reuse

Same lesson as Part 1:

```
One MongoClient per application process.
Reuse it.
Do not create a new client for every function call or request.
```

Good structure:

```python
# db.py
import os
from dotenv import load_dotenv
from pymongo import MongoClient

load_dotenv()
client = MongoClient(os.getenv("MONGODB_URI"))
db = client["collegeDB"]
```

Use anywhere:

```python
from db import db
students = db["students"]
```

Python caches imported modules, so `client` is created once and shared.

Additional notes:

```
MongoClient is thread-safe and has a built-in connection pool.
If your program forks processes (e.g. multiprocessing), create a client
inside each child process, not before the fork.
```

## 15. Context manager (clean closing)

```python
with MongoClient(uri) as client:
    client["collegeDB"]["students"].insert_one({"name": "Meera"})
# client is closed automatically here
```

Good for scripts. For long-running servers, keep one client alive and close at shutdown.

## 16. Common errors

| Error | Likely cause |
|---------|-----------------|
| `ServerSelectionTimeoutError` | cannot reach server (not running, wrong host, firewall, Atlas IP not allowed) |
| `ConnectionFailure` | connection dropped/unreachable |
| `OperationFailure: Authentication failed` | wrong credentials or auth database |
| `ConfigurationError` | bad URI or SRV/DNS lookup issue |
| `InvalidURI` | malformed URI (often un-encoded password) |
| `NameError: name 'true' is not defined` | used `true` instead of `True` |
| `bson.errors.InvalidId` | invalid string passed to `ObjectId(...)` |
| `TypeError: Object of type ObjectId is not JSON serializable` | tried `json.dumps` on a document with `ObjectId` |

The last one is very common. Fix:

```python
doc["_id"] = str(doc["_id"])
```

or use `bson.json_util.dumps(doc)`.

Debug order is the same as Node:

```
1. Is mongod / Atlas running?
2. Is the URI correct and loaded?
3. Credentials?
4. Atlas Network Access?
5. Internet/DNS?
```

## 18. Node.js vs Python — first comparison

| Point | Node.js (`mongodb`) | Python (PyMongo) |
|---------|------------------------|---------------------|
| Language style | async/await by default | synchronous by default |
| Naming | camelCase | snake_case |
| Documents | JS objects | dicts |
| Boolean/null | `true`/`null` | `True`/`None` |
| find result | cursor → `.toArray()` | cursor → `list(cursor)` |
| `_id` type | `ObjectId` | `ObjectId` |
| Higher-level layer | Mongoose | (not in this syllabus) |
| Strength | web servers/APIs | data science / AI |

Important insight:

> The database and its commands are identical. Only the language wrapper changes. If you understand MongoDB operations, switching languages is mostly syntax.

## 🚨 Common traps

1. Writing `true`/`false`/`null` instead of `True`/`False`/`None`.
2. Querying `_id` with a string instead of `ObjectId`.
3. Assuming `MongoClient()` raises an error immediately on a bad host.
4. Creating a new `MongoClient` per request.
5. Hard-coding credentials or committing `.env`.
6. Trying to `json.dumps` documents containing `ObjectId` or `datetime`.
7. Forgetting to activate the virtual environment, then "module not found".
8. Naive vs timezone-aware datetime confusion.
