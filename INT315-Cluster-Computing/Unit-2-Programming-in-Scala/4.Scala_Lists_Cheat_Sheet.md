# 📋 Scala Collections — Lists Cheat Sheet

> A complete, exam-ready reference for Scala's `List` collection — creation, access, transformation, and the core functional patterns.

---

## 🧭 Collections Overview

| Collection | Characteristics |
|---|---|
| **Array** | indexed, mutable elements |
| **List** | ordered, immutable |
| **Vector** | indexed sequence, immutable |
| **Set** | unique elements |
| **Map** | key → value |
| **LazyList** | lazy sequence |

---

## 1. `List` — Most Important Syntax

**Create:**

```scala
val nums = List(10,20,30,40,50)
```

**Access:**

```scala
nums(0)
```

**First:**

```scala
nums.head
```

**Rest:**

```scala
nums.tail
```

---

## 2. `List` — Add Elements

**Prepend:**

```scala
0 +: nums
```

or:

```scala
0 :: nums
```

**Append:**

```scala
nums :+ 60
```

**Remember:**

| Operator | Position |
|---|---|
| `+:` | beginning |
| `:+` | end |

---

## 3. `List` — Concatenation

```scala
val a = List(1,2,3)
val b = List(4,5,6)
```

**Combine:**

```scala
a ++ b
```

or:

```scala
a ::: b
```

---

## 4. `List` — `map()`

**Question:** Double every number.

```scala
val nums = List(1,2,3,4,5)

val result = nums.map(_ * 2)

result
```

**Output:**

```
List(2,4,6,8,10)
```

**Use `map()` when:**
You want to transform every element.

---

## 5. `List` — `filter()`

**Question:** Find even numbers.

```scala
val nums = List(1,2,3,4,5,6)

val even = nums.filter(_ % 2 == 0)

even
```

**Output:**

```
List(2,4,6)
```

**Use `filter()` when:**
You want to select elements satisfying a condition.

---

## 6. `List` — `foreach()`

```scala
nums.foreach(println)
```

**Difference:**

| Function | Purpose |
|---|---|
| `map` | creates transformed collection |
| `foreach` | performs side effect |

---

## 7. `List` — `sum`, `max`, `min`

```scala
nums.sum
nums.max
nums.min
nums.length
```

---

## 8. `List` — Sorting

**Ascending:**

```scala
nums.sorted
```

**Custom sorting:**

```scala
nums.sortWith(_ > _)
```

**Descending:**

```scala
nums.sortWith(_ > _)
```

---

## 9. `List` — `flatMap()`

Suppose:

```scala
val words = List("hello world", "spark scala")
```

**Use:**

```scala
words.flatMap(_.split(" "))
```

**Result:**

```
List(hello,world,spark,scala)
```

**Think:**

| Function | Behavior |
|---|---|
| `map` | transform |
| `flatMap` | transform + flatten |

---

## 10. `flatten()`

For nested lists:

```scala
val nested = List(
  List(1,2),
  List(3,4)
)
```

Then:

```scala
nested.flatten
```

**Result:**

```
List(1,2,3,4)
```

---

## 11. `reduce()`

```scala
val nums = List(1,2,3,4)

nums.reduce(_ + _)
```

**Result:**

```
10
```

**Think:**

```
1 + 2 + 3 + 4
      ↓
     10
```

---

## 12. `map` + `filter` + `reduce` 🔥

> Learn this pattern.

**Question:** Find the sum of squares of even numbers.

```scala
val nums = List(1,2,3,4,5,6)

val result = nums
  .filter(_ % 2 == 0)
  .map(x => x * x)
  .sum

result
```

**Output:**

```
56
```

**Because:**

```
2² + 4² + 6²
= 4 + 16 + 36
= 56
```

> This is the Scala version of the RDD pipeline you'll later see.
