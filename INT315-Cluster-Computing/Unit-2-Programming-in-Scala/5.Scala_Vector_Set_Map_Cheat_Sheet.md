# 🧩 Scala Collections — Vector, Set & Map Cheat Sheet

> A complete, exam-ready reference for Scala's `Vector`, `Set`, and `Map` collections.

---

## 2. Vector

**Create:**

```scala
val v = Vector(1,2,3,4,5)
```

**Access:**

```scala
v(2)
```

**Append:**

```scala
val v2 = v :+ 6
```

**Prepend:**

```scala
val v3 = 0 +: v2
```

**Update without modifying original:**

```scala
val v4 = v3.updated(3,100)
```

**Remove last:**

```scala
val v5 = v4.dropRight(1)
```

**Display:**

```scala
println(v)
println(v5)
```

**Core idea:**

```
Vector is immutable
        ↓
operations return new Vector
        ↓
original remains unchanged
```

## 3. Set

A `Set` stores **unique elements**.

```scala
val nums = Set(1,2,2,3,3,4)
```

Conceptually:

```
Set(1,2,3,4)
```

**Membership:**

```scala
nums.contains(3)
```

**Add:**

```scala
nums + 5
```

**Remove:**

```scala
nums - 2
```

## 4. Map

**Map:** key → value

**Create:**

```scala
val marks = Map(
  "Alice" -> 85,
  "Bob" -> 72,
  "Charlie" -> 91
)
```

**Access:**

```scala
marks("Alice")
```

**Output:**

```
85
```

---

### Safe Map Access

Instead of:

```scala
marks("David")
```

which can fail if the key doesn't exist, use:

```scala
marks.get("David")
```

**Possible result:**

```
None
```

Or:

```scala
marks.getOrElse("David", 0)
```

**Result:**

```
0
```

---

### Map Operations

```scala
marks.keys
marks.values
marks.contains("Alice")
```

**Add/update immutably:**

```scala
val updated = marks + ("David" -> 80)
```

**Remove:**

```scala
val removed = marks - "Bob"
```

---

### Map Filtering

**Question:** Find students with marks ≥ 80.

```scala
val result = marks.filter {
  case (name, score) => score >= 80
}

result
```

Or:

```scala
val result = marks.filter(_._2 >= 80)
```

> The second is shorter.

---

### Map Transformation

Suppose:

```scala
val marks = Map(
  "Alice" -> 85,
  "Bob" -> 72
)
```

**Add 5:**

```scala
val updated = marks.map {
  case (name, score) => (name, score + 5)
}
```

**Result:**

```
Map(Alice -> 90, Bob -> 77)
```

## 🔥 Word Frequency in Scala

> Very useful.

```scala
val words = List(
  "spark",
  "scala",
  "spark",
  "hadoop",
  "scala",
  "spark"
)
```

**Use:**

```scala
val frequency =
  words.groupBy(identity)
       .map {
         case (word, occurrences) =>
           (word, occurrences.size)
       }

frequency
```

**Conceptually:**

```
spark  → 3
scala  → 2
hadoop → 1
```
