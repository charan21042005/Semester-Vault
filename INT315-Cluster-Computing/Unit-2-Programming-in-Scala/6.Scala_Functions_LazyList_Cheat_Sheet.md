# ⚙️ Scala Functions & LazyList Cheat Sheet

> A complete, exam-ready reference for Scala functions, higher-order functions, and lazy sequences.

---

## 5. Functions

### Named Function

```scala
def square(x: Int): Int = {
  x * x
}
```

**Call:**

```scala
square(5)
```

**Output:**

```
25
```

---

### Basic Syntax

```scala
def functionName(parameters): ReturnType = {
    body
}
```

---

### Multiple Parameters

```scala
def add(a: Int, b: Int): Int = {
  a + b
}
```

**Call:**

```scala
add(10,20)
```

**Output:**

```
30
```

---

### Last Expression Is Returned

You can write:

```scala
def square(x: Int): Int = {
  x * x
}
```

No explicit `return` is required.

> The last expression becomes the result.

---

### Anonymous Function

Instead of:

```scala
def square(x: Int): Int = x * x
```

you can write:

```scala
val square = (x: Int) => x * x
```

**Call:**

```scala
square(5)
```

---

### Function Types

```scala
val square: Int => Int = x => x * x
```

Means: `Int → Int`

Another:

```scala
val isEven: Int => Boolean =
  x => x % 2 == 0
```

---

### Higher-Order Functions

A **higher-order function**:

> Takes another function as an argument or returns a function.

**Example:**

```scala
def applyFunction(x: Int, f: Int => Int): Int = {
  f(x)
}
```

Then:

```scala
applyFunction(5, x => x * 2)
```

**Result:**

```
10
```

---

### `map()` Is a Higher-Order Function

For:

```scala
List(1,2,3).map(x => x * 2)
```

`map()` receives:

```scala
x => x * 2
```

as a function.

> So `map()` is a higher-order function.

**Same idea with:**

```
filter()
reduce()
foreach()
```

## 6. Streams / LazyList

Modern Scala generally uses: **`LazyList`**

**Example:**

```scala
val nums = LazyList.from(1)
```

This can represent:

```
1,2,3,4,5,6,...
```

without immediately creating the entire infinite sequence.

**Take first five:**

```scala
nums.take(5).toList
```

**Result:**

```
List(1,2,3,4,5)
```

---

### Lazy Processing

```scala
val nums = LazyList.from(1)

val even = nums.filter(_ % 2 == 0)

even.take(5).toList
```

**Result:**

```
List(2,4,6,8,10)
```

---

### Important

| Collection | Evaluation |
|---|---|
| `List` | eager |
| `LazyList` | lazy |

> And don't confuse this with:
>
> ```
> Scala LazyList/Stream
>         ≠
> Spark Streaming
> ```
