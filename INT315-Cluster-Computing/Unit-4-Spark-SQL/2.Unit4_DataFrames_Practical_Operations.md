### 1. First, understand what a DataFrame actually represents

Imagine a college maintains this student dataset:

| student_id | name | department | age | marks |
| --- | --- | --- | --- | --- |
| 101 | Alice | CSE | 21 | 85 |
| 102 | Bob | ECE | 22 | 72 |
| 103 | Charlie | CSE | 21 | 91 |
| 104 | David | IT | 23 | 65 |
| 105 | Emma | ECE | 22 | 88 |

This is exactly the kind of structured data Spark SQL is designed to process.

Let's understand its structure.

```text
                 DATAFRAME
                     |
        ┌────────────┼────────────┐
        ↓            ↓            ↓
      ROWS         COLUMNS       SCHEMA
        |            |            |
     Records      Attributes   Data types
        |            |            |
     Students       Name         String
                    Age          Integer
                    Marks        Integer
```

**Three important terms**

#### 1. Row

A row represents one record.

**Example:**

```text
101, Alice, CSE, 21, 85
```

#### 2. Column

A column represents one attribute of the records.

**Examples:**

- `student_id`
- `name`
- `department`
- `age`
- `marks`

#### 3. Schema

A schema defines the structure of the DataFrame, including column names and data types.

**Example:**

| Column | Data type |
| --- | --- |
| `student_id` | Integer |
| `name` | String |
| `department` | String |
| `age` | Integer |
| `marks` | Integer |

Remember: A DataFrame is not simply a Scala collection or an ordinary table stored on one machine. It is a distributed, structured dataset managed by Spark.

### 3. Creating our first DataFrame

There are several ways to create a DataFrame.

We'll first learn the easiest method.

**Method 1 — Using a Scala Sequence and toDF()**

**Create student records**

```scala
val studentData = Seq(
  (101, "Alice", "CSE", 21, 85),
  (102, "Bob", "ECE", 22, 72),
  (103, "Charlie", "CSE", 21, 91),
  (104, "David", "IT", 23, 65),
  (105, "Emma", "ECE", 22, 88)
)
```

**What is Seq?**

Seq is a Scala collection representing an ordered sequence of elements.

Each tuple represents one student.

For example:

```scala
(101, "Alice", "CSE", 21, 85)
```

means:

| Field | Value |
| --- | --- |
| `student_id` | 101 |
| `name` | Alice |
| `department` | CSE |
| `age` | 21 |
| `marks` | 85 |

Now convert it into a DataFrame:

```scala
val studentsDF = studentData.toDF(
  "student_id",
  "name",
  "department",
  "age",
  "marks"
)
```

**Display**

```scala
studentsDF.show()
```

**Expected output**

```text
+----------+-------+----------+---+-----+
|student_id|   name|department|age|marks|
+----------+-------+----------+---+-----+
|       101|  Alice|       CSE| 21|   85|
|       102|    Bob|       ECE| 22|   72|
|       103|Charlie|       CSE| 21|   91|
|       104|  David|        IT| 23|   65|
|       105|   Emma|       ECE| 22|   88|
+----------+-------+----------+---+-----+
```

**Important syntax**

```scala
val df = data.toDF("column1", "column2", "column3")
```

**When to use: When you have a small Scala collection and want to convert it quickly into a DataFrame.**

Select only one column

```scala
studentsDF.select("name").show()
```

Select multiple columns

### 8. Selecting columns with aliases

Suppose you want to display:

| Original column | Output name |
| --- | --- |
| `name` | `student_name` |
| `marks` | `total_marks` |

**Use alias()**

```scala
studentsDF.select(
  col("name").alias("student_name"),
  col("marks").alias("total_marks")
).show()
```

**Expected output**

```text
+------------+-----------+
|student_name|total_marks|
+------------+-----------+
|       Alice|         85|
|         Bob|         72|
|     Charlie|         91|
|       David|         65|
|        Emma|         88|
+------------+-----------+
```

You can also use:

```scala
studentsDF.selectExpr(
  "name AS student_name",
  "marks AS total_marks"
).show()
```

**Remember**

```scala
col("marks").alias("total_marks")
```

means:

Select the marks column and give it a different output name.

It does not permanently rename the original column.

### 9. Filtering records using filter() and where()

Very important for practicals
Suppose the examiner asks:

**Display students who scored more than 80 marks.**

**Use**

```scala
studentsDF.filter(col("marks") > 80).show()
```

**Expected output**

```text
+----------+-------+----------+---+-----+
|student_id|   name|department|age|marks|
+----------+-------+----------+---+-----+
|       101|  Alice|       CSE| 21|   85|
|       103|Charlie|       CSE| 21|   91|
|       105|   Emma|       ECE| 22|   88|
+----------+-------+----------+---+-----+
```

**General syntax**

```scala
df.filter(condition)
```

**Alternative: where()**

```scala
studentsDF.where(col("marks") > 80).show()
```

Both filter() and where() are equivalent for DataFrame filtering.

**More filtering examples**

Marks greater than or equal to 80:

```scala
studentsDF.filter(col("marks") >= 80).show()
```

Students belonging to CSE:

```scala
studentsDF.filter(col("department") === "CSE").show()
```

Students aged 21:

```scala
studentsDF.filter(col("age") === 21).show()
```

Students not belonging to CSE:

```scala
studentsDF.filter(col("department") =!= "CSE").show()
```

**Notice something important:**

===========================

=!=

These are Spark column-expression equality and inequality operators in Scala.

### 10. Combining multiple filtering conditions

Now imagine the question is:

Find CSE students who scored more than 80.

We need two conditions.

```scala
studentsDF.filter(
  (col("department") === "CSE") &&
  (col("marks") > 80)
).show()
```

**Expected output**

```text
+----------+-------+----------+---+-----+
|student_id|   name|department|age|marks|
+----------+-------+----------+---+-----+
|       101|  Alice|       CSE| 21|   85|
|       103|Charlie|       CSE| 21|   91|
+----------+-------+----------+---+-----+
```

**AND condition**

Both conditions must be true.

```scala
studentsDF.filter(
  (col("age") > 20) &&
  (col("marks") > 80)
).show()
```

**OR condition**

At least one condition must be true.

```scala
studentsDF.filter(
  (col("department") === "CSE") ||
  (col("department") === "ECE")
).show()
```

**NOT condition**

```scala
studentsDF.filter(
  !col("department").isin("CSE", "ECE")
).show()
```

**Using isin()**

Find students belonging to CSE or ECE:

```scala
studentsDF.filter(
  col("department").isin("CSE", "ECE")
).show()
```

**Exam memory:**

| Requirement  | Syntax |
| ------------ | ------ |
| AND          | &&     |
| OR           |        |
| NOT          | !      |
| Equal        | ===    |
| Not equal    | =!=    |
| Greater than | >      |
| Less than    | <      |
| Membership   | isin() |

### 17. Conditional columns using when() and otherwise()

This is a very useful practical pattern.

Question:

Create a new column called result. If marks are 80 or above, assign PASS; otherwise assign FAIL.

**Code**

```scala
val resultDF = studentsDF.withColumn(
  "result",
  when(col("marks") >= 80, "PASS")
  .otherwise("FAIL")
)
```

**Display**

```scala
resultDF.show()
```

**Expected output**

| name | marks | result |
| --- | --- | --- |
| Alice | 85 | PASS |
| Bob | 72 | FAIL |
| Charlie | 91 | PASS |
| David | 65 | FAIL |
| Emma | 88 | PASS |

**Understand the syntax**

```scala
when(condition, value_if_true)
  .otherwise(value_if_false)
```

**Multiple conditions**

Suppose:

- Marks 90 or above → Excellent
- Marks 75 or above → Good
- Otherwise → Needs Improvement

```scala
val gradeDF = studentsDF.withColumn(
  "grade",
  when(col("marks") >= 90, "Excellent")
  .when(col("marks") >= 75, "Good")
  .otherwise("Needs Improvement")
)
```

This is extremely useful for real-world data transformation.

### 18. Handling null values

Real-world datasets often contain missing values.

Example:

```scala
val employeeData = Seq(
  ("Alice", 50000),
  ("Bob", null.asInstanceOf[java.lang.Integer]),
  ("Charlie", 60000)
)
```

```scala
val employeeDF = employeeData.toDF(
  "name",
  "salary"
)
```

**Display**

```scala
employeeDF.show()
```

You can find records with null salaries:

```scala
employeeDF.filter(
  col("salary").isNull
).show()
```

Find records without null salaries:

```scala
employeeDF.filter(
  col("salary").isNotNull
).show()
```

Replace null values:

```scala
employeeDF.na.fill(0, Seq("salary")).show()
```

Remove rows containing null values:

```scala
employeeDF.na.drop().show()
```

**Important null methods**

| Method | Purpose |
| --- | --- |
| isNull | Find null values |
| isNotNull | Find non-null values |
| na.fill() | Replace nulls |
| na.drop() | Remove rows containing nulls |

### 20. Understanding immutability in DataFrames

This concept is important for interviews and viva.

Consider:

```scala
val newDF = studentsDF.withColumn(
  "bonus",
  col("marks") + 5
)
```

Did studentsDF change?

No.

Why?

Spark DataFrames are immutable.

```text
Original DataFrame
       |
       ↓
 withColumn()
       |
       ↓
 New DataFrame
```

The original DataFrame remains available.

Example:

```scala
studentsDF.show()
```

Still displays original marks.

```scala
newDF.show()
```

**Displays the additional bonus column.**

**Strong viva answer:**

DataFrames are immutable in Spark. Transformations such as select(), filter() and withColumn() produce new DataFrames instead of modifying the original DataFrame.

### 21. Transformation versus Action in DataFrames

Remember this from RDDs?

The same broad concept applies here.

**Transformations**

Operations that construct a new DataFrame or query plan.

Examples:

```scala
studentsDF.select("name", "marks")
```

```scala
studentsDF.filter(col("marks") > 80)
```

```scala
studentsDF.withColumn("bonus", col("marks") + 5)
```

```scala
studentsDF.drop("age")
```

These are generally lazily evaluated.

**Actions / operations that trigger execution**

Examples:

```scala
studentsDF.show()
```

```scala
studentsDF.count()
```

```scala
studentsDF.collect()
```

```scala
studentsDF.first()
```

These trigger computation to produce results or side effects.

**Important: Spark SQL uses lazy query planning and execution, and not every DataFrame method fits into a simplistic RDD-style classification. For practical understanding, remember that transformations build a plan and result-producing actions trigger execution.**

| toDF() not recognised | Run import spark.implicits._ |
| col() not recognised | Run import org.apache.spark.sql.functions._ |
| Wrong column name | Check df.columns |
| Using = for column equality | Use === |
| Using != for column inequality | Use =!= |
| Expecting withColumn() to change the original | Assign the returned DataFrame |
| Using collect() on huge data | Use show() or take() |
| Forgetting to display an operation's result | Append .show() |
| Expecting distinct() to deduplicate one column only | Use select("column").distinct() |

One additional Spark Shell warning: if you already declared a val and try to declare it again in the same REPL scope, you may get a redefinition error. Use a different name such as studentsDF2 or restart the shell when necessary.

### 25. Phase 2 — viva questions and answers

Here are 20 important questions for this phase.

#### Q1. What is a DataFrame?

A DataFrame is a distributed collection of structured data organised into named columns.

#### Q2. What is a row?

A row represents one record in a DataFrame.

#### Q3. What is a column?

A column represents one attribute of the records.

#### Q4. What is a schema?

A schema defines the column names and corresponding data types.

#### Q5. How do you create a DataFrame from a Scala collection?

```scala
val df = data.toDF("name", "marks")
```

#### Q6. Why do we import spark.implicits._?

It provides convenient implicit conversions, including toDF() for supported Scala collections and encoders.

#### Q7. What does show() do?

It displays DataFrame records in a tabular format.

#### Q8. What does printSchema() do?

It displays the schema and data types in a tree format.

#### Q9. How do you select particular columns?

Using select().

#### Q10. What is the difference between filter() and where()?

Both perform DataFrame filtering and are equivalent in this context.

#### Q11. What does withColumn() do?

It adds a new column or replaces an existing column with a new expression.

#### Q12. What does withColumnRenamed() do?

It renames an existing column.

#### Q13. What does drop() do?

It removes specified columns from the resulting DataFrame.

#### Q14. What does distinct() do?

It removes duplicate complete rows.

#### Q15. What is alias()?

It assigns an alternative name to a column expression in the query result.

#### Q16. What is col()?

It creates a column expression referencing a DataFrame column.

#### Q17. What is lit()?

It creates a literal-value column expression.

#### Q18. What is the purpose of when()?

It creates conditional expressions, generally combined with otherwise().

#### Q19. Are DataFrames mutable?

No. DataFrames are immutable, and transformations return new DataFrames.

#### Q20. What is the difference between collect() and show()?

collect() returns all rows to the driver, whereas show() displays a limited number of rows by default.

### 26. Phase 2 — final master code revision

This is the practical sequence I want you to become comfortable writing without referring to notes.

```scala
// Import required functionality
import spark.implicits._
import org.apache.spark.sql.functions._

// Create data
val studentData = Seq(
  (101, "Alice", "CSE", 21, 85),
  (102, "Bob", "ECE", 22, 72),
  (103, "Charlie", "CSE", 21, 91),
  (104, "David", "IT", 23, 65),
  (105, "Emma", "ECE", 22, 88)
)

// Create DataFrame
val studentsDF = studentData.toDF(
  "student_id", "name", "department", "age", "marks"
)

// Display
studentsDF.show()
studentsDF.printSchema()

// Inspect
studentsDF.columns
studentsDF.count()
studentsDF.first()
studentsDF.take(3)

// Select
studentsDF.select("name", "marks").show()

// Filter
studentsDF.filter(col("marks") > 80).show()

// Multiple conditions
studentsDF.filter(
  (col("department") === "CSE") &&
  (col("marks") > 80)
).show()

// Add column
studentsDF.withColumn(
  "bonus_marks",
  col("marks") + 5
).show()

// Rename column
studentsDF.withColumnRenamed(
  "name", "student_name"
).show()

// Drop column
studentsDF.drop("age").show()

// Remove duplicate records
studentsDF.distinct().show()

// String operations
studentsDF.select(
  upper(col("name"))
).show()

// Conditional column
studentsDF.withColumn(
  "result",
  when(col("marks") >= 80, "PASS")
  .otherwise("FAIL")
).show()

// Sort
studentsDF.orderBy(
  col("marks").desc
).show()

```
