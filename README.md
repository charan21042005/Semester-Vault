## 📌 Executive Summary

The **Semester Vault** is a centralized, version-controlled repository serving as a comprehensive knowledge base for my academic coursework. It encapsulates lecture notes, technical documentation, architectural diagrams, and practical implementations focusing on distributed systems, large-scale data processing, and modern database architectures.

This repository demonstrates practical proficiency in industry-standard technologies and methodologies, emphasizing high availability, distributed computing, and intelligent data modeling.

---

## 🛠️ Core Competencies & Technologies

Throughout this semester, the coursework and associated projects focus on the following tech stack:

- **Distributed Computing:** Apache Spark (RDDs, DataFrames, Spark SQL), Apache Kafka
- **Machine Learning:** PySpark, Spark MLlib (Regression, Clustering, Classification)
- **Database Systems:** MongoDB, NoSQL Data Modeling, Aggregation Frameworks
- **Languages:** Scala, Python, Node.js (Mongoose)

---

## 📚 Academic Modules

### ☁️ [INT315: Cluster Computing](./INT315-Cluster-Computing)
An in-depth exploration of cluster architectures and distributed data processing. 
* **Key Focus Areas:** Hadoop MapReduce limitations, Apache Spark ecosystem, stream processing via Apache Kafka, and scalable machine learning using Spark MLlib.
* **Navigation:** [`/INT315-Cluster-Computing`](./INT315-Cluster-Computing)

### 🗄️ [CSE494: Intelligent NoSQL Databases](./CSE494-Intelligent-NoSQL-Databases)
A comprehensive study of non-relational database systems, focusing on MongoDB.
* **Key Focus Areas:** Document-oriented data modeling, schema design, advanced indexing, aggregation pipelines, and integration of databases with AI-driven analytics.
* **Navigation:** [`/CSE494-Intelligent-NoSQL-Databases`](./CSE494-Intelligent-NoSQL-Databases)
